
# Restaurant Management System

A Java-based desktop restaurant management system developed using client-server architecture, multithreading, and object-oriented programming (OOP).

The application provides an integrated interface for restaurant administration, including menu management, table reservations, user management, and operational reporting.

## Overview

Developed collaboratively as a university project, this system aims to simplify restaurant operations through a centralized management application.

The project incorporates Java GUI development, client-server communication, multithreading, and file handling for data persistence.

## Technologies & Concepts

- **Programming Language:** Java
- **Architecture:** Client-Server
- **Concurrency:** Multithreading
- **Programming Paradigm:** Object-Oriented Programming (OOP)
- **Interface:** Java Desktop GUI
- **Data Management:** File Handling
- **Development Environment:** NetBeans

## Features

### Table Management & Reservations
- Add restaurant tables with unique IDs, categories, and seating capacities.
- Edit and remove existing tables.
- Manage table reservations and availability.
- Display table information, reservation counts, and reservation status.
- Search and manage restaurant tables through an interactive interface.
- Generate table reports and reservation statistics.

### Menu Management
- Add meal categories and menu items.
- View and manage restaurant menu information.
- Track frequently ordered meals.

### User Management
- Manage restaurant users and their information.
- View and maintain user records.

### Reports & Statistics
- View restaurant operational statistics.
- Analyze table reservations and utilization.
- Display receptionist and guest statistics.
